What is Tailwind CSS?

Tailwind is a utility-first CSS framework. Instead of writing custom CSS, you apply pre-built classes directly in your HTML — making styling fast, consistent, and responsive.

Try the Class Activity ↓

Core Utility Classes

Every visual property is a class — no custom CSS needed!

📐

Spacing

p- for padding, m- for margin. Numbers follow a 4px scale.

p-1 = 4px
p-2 = 8px
p-4 = 16px
🎨

Colors

text-, bg-, border- with color + shade.

red-400
grn-400
blu-400
yel-400
pnk-400
gry-700
📱

Responsive

Prefix classes with breakpoints: sm: md: lg:

class="text-sm md:text-lg lg:text-2xl"

→ Font changes size at each breakpoint automatically!

Flexbox & Buttons

Use flex, gap-, rounded-, and state variants like hover:

/* Example: Primary button */

<button class="bg-indigo-600 text-white px-6 py-3 rounded-lg hover:bg-indigo-700 transition"> Click me </button>

🏆 Class Activity!

Can you build a profile card using only Tailwind classes?

Your task — build a card that has:

  • 1 A colored background (e.g. bg-blue-500)
  • 2 Rounded corners (rounded-xl) and a shadow (shadow-md)
  • 3 A name in bold white text and a role in smaller light text
  • 4 A button at the bottom with hover: effect

💡 Sample Answer:

<div class="bg-blue-600 text-white p-6 rounded-xl shadow-md max-w-xs"> <h2 class="text-xl font-bold">Priya Nair</h2> <p class="text-sm text-blue-200 mb-4">Frontend Developer</p> <button class="bg-white text-blue-600 px-4 py-2 rounded hover:bg-blue-50"> View Profile </button> </div>
